Full harness component table mapped to PEAS with alternatives and MVP guidance

Component PEAS bucket Implementation alternatives MVP version
Sensors — percepts
Tool result ingestion Sensors Anthropic tool use · OpenAI function calling · LangChain tool schema · raw JSON parsing Parse tool_use block from model response. Run the function. Append tool_result message. The native API handles the schema.
RAG / retrieval Sensors LlamaIndex · LangChain retrievers · pgvector · BM25 · Cohere reranker Embed query with text-embedding-3-small. Cosine search on a Chroma collection. Prepend top-3 chunks to context.
Long-term memory read Sensors pgvector · Pinecone · Chroma · Redis · SQLite FTS5 SQLite table with FTS5. Full-text search on past sessions. Swap for vector DB only when semantic retrieval is measurably needed.
Agent program — execution engine
Agent loop Agent program LangGraph · CrewAI · AutoGen · DSPy · custom while-loop A while not done loop: call LLM → parse tool call → execute → append result → repeat. ~50 lines of Python.
Context assembly Agent program LangChain prompt templates · Jinja2 · Guidance · LMQL · raw f-strings Build a list of dicts: system prompt + memory snippets + tool results. No framework needed.
Context window manager Agent program tiktoken truncation · LlamaIndex splitter · sliding window · summarisation compressor Count tokens with tiktoken. Drop oldest non-system messages when over 80% of limit.
Planning / task decomp. Agent program ReAct · LATS · Tree-of-Thought · Plan-and-Execute · scratchpad in system prompt Add to system prompt: "Think step by step before calling any tool." ReAct emerges for free from the loop.
Multi-agent orchestration Agent program LangGraph multi-agent · CrewAI · AutoGen group chat · OpenAI Swarm · router LLM call Skip until needed. If forced: a router LLM call picks which specialist prompt to use, then runs the same single-agent loop.
Agent program — internal state
Short-term memory Agent program Raw message list · LangChain ConversationBufferMemory · token-aware trimmer Keep the full messages[] array in process memory. That's it.
Long-term memory write Agent program pgvector · Pinecone · Chroma · Zep · SQLite After each session, upsert a summary + embeddings into SQLite. No framework needed.
Session checkpointing Agent program LangGraph checkpointer · Redis snapshots · Postgres JSONB · file-based JSON Serialize messages[] to a JSON file keyed by session ID. Load on resume.
Agent program — skills
Tool registry Agent program JSON Schema defs · OpenAPI → tools · LangChain @tool · MCP server A Python dict mapping tool names to functions. Pass JSON schemas in the tools field.
Progressive disclosure Agent program Dynamic tool injection · MCP namespaces · LangChain toolkits · meta-call to select tools Start with all tools always loaded. Only optimise when context pressure becomes a real problem.
Actuators — action space
Tool execution Actuators Direct function call · MCP tool runner · LangChain tool executor · custom dispatcher A dispatch(tool_name, args) function that looks up the registry dict and calls the function.
Sandbox / isolation Actuators Docker + subprocess · E2B · Modal · Daytona · Firecracker microVM subprocess.run(..., timeout=10) with a restricted user, no network. Upgrade to Docker when code execution is a core feature.
UI output — alongside actuators
Streaming responses Actuators SSE · WebSockets · AG-UI spec · LangGraph streaming · raw stream=True Pass stream=True to the API. Forward chunks over SSE. One endpoint, ~20 lines.
State push / AG-UI Actuators AG-UI protocol · custom WebSocket events · Phoenix LiveView · polling Emit a JSON event on each loop iteration: {step, tool_called, status}. The UI polls or listens via SSE. Adopt AG-UI when the event schema becomes painful to maintain manually.
HITL — interrupt points
Plan approval HITL LangGraph interrupt · Slack approval bot · email confirmation · CLI prompt After planning step, print proposed plan and block on input("Proceed? y/n"). That's a HITL.
Action approval HITL LangGraph interrupt · custom approval queue · Slack bot · webhook callback Before any irreversible tool call (send email, delete, write to DB), pause and require explicit confirmation. Same pattern as plan approval.
Guardrails + evaluation — performance measure
Input/output validation Perf. measure Guardrails AI · NeMo Guardrails · Pydantic · Instructor · LLM-as-judge · regex Validate tool call args with Pydantic before execution. Catch ValidationError, re-prompt once with the error.
Permissions / least privilege Perf. measure RBAC middleware · allow-list per session · OAuth scopes · capability flags per tool Hard-coded allow-list of tools per agent role. Check before dispatch. No framework needed.
Cost / token budget Perf. measure LiteLLM budget manager · Helicone · PromptLayer · manual token counting Count tokens before each LLM call. Raise an exception if cumulative spend exceeds a per-session threshold.
Error recovery Perf. measure Tenacity retry · exponential backoff · fallback model · re-plan on failure · LangGraph error edges try/except around every tool call. Append the error as a tool_result and let the model decide to retry or abandon.
Quality metrics Perf. measure LLM-as-judge · RAGAS · DeepEval · human eval pipeline · task success rate Log task success/failure manually. Run an LLM-as-judge prompt on a sample of outputs once a week. No tooling needed yet.
Debug & trace — developer sidebar
Execution tracing Dev sidebar LangSmith · LangFuse · Arize Phoenix · OpenTelemetry · W&B Traces print() every LLM call: model, tokens, tool called, latency. Structured JSON to stdout. Wire to a real tracer later.
Token & cost logging Dev sidebar LiteLLM callbacks · Helicone · custom middleware · OpenTelemetry metrics Log usage.input_tokens and usage.output_tokens from every API response to a CSV. Analyse in a spreadsheet.
Tool call inspection Dev sidebar LangSmith tool trace · LangFuse spans · custom logging middleware · replay buffer Log tool name, args, result, and duration to a JSON file on every call. Grep it when debugging.
